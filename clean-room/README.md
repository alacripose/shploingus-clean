# shploingus — the clean room

**New code beside the old tree.** This directory is the clean-room regeneration of the Shploingus
game and its API layers. It never imports the legacy implementation under `../crates/`; the legacy
tree is a behavioural **witness**, and the clean room is written from documents, papers and declared
formats (Constitution P7).
