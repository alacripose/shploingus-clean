MAP-0001 — the map window's all view
============================================

# Change

Generate `MAP-0001`, the map window's `all` view, from the world's own laws at seed
`9418646105956113635` and tick `81000`: every cell is one `terrain::elevation_m` sample and one
`ecology::biome_at` reading on the same Holdridge inputs the chunk builder uses, at
32 m a cell. Every cell is in its biome's own ink; this is the map `plan all` returns.

The view is centred on the game's spawn column, because the default map is the map of
where the player is.

The frame is a declaration in the cellframe grammar, addressed to `map-plan`'s content
space, with `feature all`. The mount grades all seven views when it opens the
package; `plan all` selects this one and never re-reads a file.

**The declaration is GPU-first.** The frame names the fields (`terrain::elevation_m`,
`ecology::biome_at`), the per-axis cell law (`profile32` at 32 divisions), the orthographic
camera and a 28 × 32 cell terrain extent at 32 m a cell;
the shell samples those laws and draws the heightfield through the world's own pipeline,
tilted -24° so the horizon is in the window. **The glyph rows below are the
fallback**, kept for a host with no GPU surface: they are the same view drawn as a
character grid, not a second map.

# Acceptance

- `voxel-layers` names `MAP-0001` in the `alpha-shell` emit and prints it with this record;
the recipe names it by a `row` and the two package copies are byte-identical.
- The frame is 56 × 22 and fits `map-plan`'s declared extent (56 × 8 dp and 22 × 16 dp
inside 480 × 440 dp); a frame larger than the window is refused by cell count.
- `plan all` selects it in the console; `plan next` reaches it by cycling; `plan all`
returns `MAP-0001`; an undeclared token is refused by name and changes nothing.
- The picture is the generator's own: `voxel-mapframe --check` regenerates every view
and compares every row and this record, and exits non-zero on the first difference.

# Evidence

- `cargo run -p voxel-package --bin voxel-mapframe` — writes `MAP-0001..0007`, exit 0.
- `cargo run -p voxel-package --bin voxel-mapframe -- --check` — every picture and
record is the generator's, exit 0.
- This view's reading: 918 of 918 cells answer `all`; land is 39%
of the disc; the highest cell in the window is 23.1 m; 7 of 11 biomes
are present at this centre.
- `cargo test -p voxel-package cellframe::` — the grammar's own refusals, including the
optional `feature` key: it may be absent, may not be declared twice, and may not carry
a token the console could not type.

# Rollback

Delete `frames/MAP-0001.frame`, `frames/MAP-0001.md` and the `row MAP-0001` line in
`package.shspec` (and its copy in `packages/alpha-shell.shspec`). The package then
carries six views; the mount grades what is left and `plan` lists only those tokens.
Deleting all seven returns the shell to composed elements, exactly as before the frames
existed. No code is reverted.
