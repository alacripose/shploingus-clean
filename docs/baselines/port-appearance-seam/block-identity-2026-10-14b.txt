What this does and does not establish
-------------------------------------
It establishes that the parent-vs-this-crate comparison **did not move** when the keyed door landed: the
same 8 cases, the same 16 558 unit faces owned on the parent's side, the same 15 406 divergent faces, the
same 0 unnamed, row for row and example for example. It does not establish that the two *capture files* are
byte-identical as files — they are not, and should not be read as such: the difference is which harness
lines each extraction kept, which is why the figure in README.txt §9 is stated per kind (240) rather than as
a file length (249 / 250).
