# Change

Declare the shell's first cell data frame: a 56 × 22 grid addressed to the content space of the
`map-plan` window, carrying the map's lattice in the schema's divider role and its contour lines in
the accent, with the border and the legend in the window's own chrome and ink.

The frame exists because **a window's content has to be a declaration before it is a drawing**. The
map window is the first window whose content is cells rather than composed panels: it is a lattice
of cells with contours over it, and every cell is addressed from the window's content space, so the
frame cannot reach the bar, the title bar or a neighbour's rect (PATCH-075's rule, kept).

The cells are written here rather than streamed from the world. **That is the honest limit of this
frame**: the format, the mount join and the graded draw path are real, and the generator that fills
the same type from the world's height field is the next pass. A declared frame is a drawing the
package carries, exactly as `LOD-0001` is a drawing the package carries.

# Acceptance

- `voxel-layers` names the frame in the `alpha-shell` emit, and the row it is named by is the row
  the recipe carries: a frame the recipe names by no row is refused by file and id.
- A frame addressed to a window the package does not declare is refused with both ids; a frame
  larger than that window's declared extent is refused by cell count (56 × 8 and 22 × 16 dp fit
  inside the 480 × 440 dp `map-plan`).
- The shell draws these cells **only** from a frame the mount graded: content that is not a declared
  frame stays composed elements, and a package that carries no frame draws no cells at all.
- The record's four sections are read by the same renderer as a layer's, and a missing section is
  refused by the section's name.

# Evidence

* `cargo run -p voxel-package --bin voxel-layers -- display-packages/alpha-shell` — the `frames 1`
  row, the frame's one-line description, and the rendered block, exit 0.
* `cargo test -p voxel-package cellframe::` — the grammar's own refusals: an unknown key, a duplicate
  key, a missing key, a row outside the grid, a frame that draws nothing, an old header, and a
  record without `# Rollback`.
* `docs/baselines/mount-v2-shell-cells-2026-10-24/` — the emit before and after, both digests, and
  the test readings.

# Rollback

Delete `frames/MAP-0001.frame`, `frames/MAP-0001.md` and the `row MAP-0001` line in
`package.shspec` (and its copy in `packages/alpha-shell.shspec`). The package then declares no
frame, the mount registers none, and every window draws composed elements as it did before the
frames existed. No code is reverted: the frame path with no frame is the shell it replaced.

# Change

Add a `terrain-lod` layer that draws the rung `voxel_stream::horizons` chooses for the horizon, with
its own shader (`src/LOD-0001.wgsl`), one bind group and three uniforms: the camera's `view_proj`, the
rung index, and the rung's declared colour.

The layer exists because **a package can express only what its layers name**. `voxel_stream` chooses
the rung and `voxel-client::world` draws it, but a package that can name only the near ring is a
package for an island — and this world is planetary: terrain at a distant horizon is drawn from the
rung, not from the near mesh (M10.0.2).

# Acceptance

The horizon sweep — the eye at the world's scale, the far ring beyond the near one — draws the far
terrain through this layer, at the rung `horizons` chose, with **no hole and no double geometry at the
handoff**. A package whose layer writes `shading.wgsl` is refused with the layer id and the path in
the same sentence (`voxel_package::layer`), and a layer declared but named by no row is refused with
both files named.

The rendered recipe is byte-stable across two runs: `voxel-layers` over this folder prints the same
bytes twice, and the reading is kept in `docs/baselines/mount-v2/layer-recipes-2026-10-24.txt`.

  a record without `# Rollback` refused.
* `docs/baselines/mount-v2/layer-recipes-2026-10-24.txt` — the command and its verbatim output.

the id, so no code change is needed and no window moves.
