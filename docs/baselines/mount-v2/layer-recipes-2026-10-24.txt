The layer recipes and package rows, rendered from the display packages' own declarations — 2026-10-24
=====================================================================================================

Subject: M10.2's acceptance — *a rendered recipe for the fixture package that names every layer,
every window and every row, with no path that exists only in the prose; and the recipe is byte-stable
across two runs.* This is the one command that answers it, run from the workspace root on the final
bytes, after the two documents added on 2026-10-24 were consumed into `worldgen/`.

What is measured, and why these are the numbers
-----------------------------------------------

`voxel-layers` walks `display-packages/` and, for every folder holding a `package.shspec`:

* parses the folder's recipe (`shploingus.recipe/3`) — the join a layer is named by — and prints its
  name and version, **every window id**, every home (tab, bar, filed, pin), and **every row** with
  the record's own words;
* parses each `layers/<id>.layer` (`shploingus.layer/1`), refusing a shader naming `shading.wgsl` or
  any path outside the package's own `src/`, an unknown key, a duplicate, a missing key, or a file
  name that disagrees with the layer's id;
* requires a `row` in that recipe whose id **is** the layer's id, so a layer the package does not name
  is refused rather than printed as if it were carried;
* requires the shader file the layer names to exist under the package and hold bytes — a layer that
  names a shader it does not carry is a pass that draws nothing;
* reads `layers/<id>.md` and requires all four sections (`# Change`, `# Acceptance`, `# Evidence`,
  `# Rollback`), each with text under it;
* renders the pair as one block.

The counts follow from the folders, not from a literal: **3** folders measured, **1** layer declared
with **3** uniforms, **3** rows, **0** refusals. `alpha-shell` reports 16 windows, 6 tabs, the console
bar entry, 6 filed windows and 3 pins, and `layers none declared` — the honest state of a package that
draws with the renderer's own pipelines. `worldgen` reports no window, no layer and three rows.

What the output says, one clause at a time
------------------------------------------

* **The package header is the recipe's own, not a paraphrase.** `package alpha-shell v1-alpha`, then
  the 16 window ids, the six tabs in strip order, `bar console`, the six `filed` homes, the three
  pins, and `rows none`. A reader can check every line against `package.shspec` without opening it,
  and a window with no home would be visibly absent from all four lists.
* **Every field of the layer declaration is in the block.** `id LOD-0001`, `pipeline terrain-lod`,
  `shader src/LOD-0001.wgsl`, `entry fs_horizon`, `bind-group 1`, the three uniforms with their
  declared types and byte counts, `lod 0`, `order 10`, `requires none`.
* **The four sections are the record's, verbatim.** Nothing in the block is written twice: the prose
  under `# Change`, `# Acceptance`, `# Evidence` and `# Rollback` is `layers/LOD-0001.md`'s own text,
  and a record missing a section is refused by the section's name rather than rendered short.
* **The join is the row.** `horizon-lod`'s `row LOD-0001` is what names the layer; the reader refuses
  a layer the recipe names by no row, so the block cannot show a layer the package does not carry.
  That is M10.1 item 3 made mechanical without a new recipe column (`R-64.1`).
* **`worldgen` is the two documents, consumed as rows.** `OPT-0001`, `ORO-0001` and `WAV-0001` each
  carry the 1/32 cubic-field shaper scale in their own words, and `OPT-0001` carries **both** optical
  mechanisms because the two documents disagree: the PDF says a classic 22° halo *cannot be
  confirmed* from the photograph, the Markdown asserts it. The package keeps the disagreement instead
  of resolving it by fiat.
* **The look is not a layer's.** The grammar refuses `shading.wgsl` by name, with the layer id and
  the path in the sentence (`C-33`, `AR15`). That refusal is held by
  `cargo test -p voxel-package layer::` — 11 tests, including the look, a shader outside `src/`, an
  unknown key, a duplicate key, a missing key, and a record without `# Rollback`.

**Two runs, one digest.** The render is assembled from ordered vectors and the files' own lines, so
it does not depend on a map's iteration order, on the platform's path separator (the reader writes
`/`), or on the clock. That is the property M10.2 asks for, and the reason it is stated as a command
rather than as a sentence.

What this does not prove
------------------------

* **No pixel is drawn by this record.** `Mount::load_display_package` (M10.3) does not exist, so the
  packages are source a human reads and a test checks; the horizon sweep's drawn witness is M10.3's
  and is not claimed here.
* **No physics is implemented by `worldgen`.** Its rows are the contract. `ORO-0001` and `OPT-0001`
  are owed shaper and sky-transport measurements, and `WAV-0001` has **no module today** — the row is
  open, and no layer, shader or frame may pretend it ran.
* **`claims.shpkg` is absent** from every package. The axis package's claims/pin/reproduce file is
  M10.3's; nothing writes one today, and a placeholder would be a claim nobody made.
